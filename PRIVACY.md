# Privacy and data handling / Tietosuoja ja tietojen käsittely

**Project / Projekti:** Access & Subtitle QA Toolkit  
**Last reviewed / Tarkistettu:** 11 November 2026

## Suomeksi

### Soveltamisala
Julkaistu selain-demo käsittelee liitetyn HTML-koodin ja valitut SRT- tai WebVTT-tekstitystiedostot paikallisesti käyttäjän selaimessa. Sisältöä ei ladata projektin palvelimelle eikä selain-demossa ole projektin omaa analytiikkaa, käyttäjätilejä tai evästeitä. PHP-komentorivityökalu on erillinen paikallinen työkalu. Älä käytä julkista demoa luottamuksellisten, arkaluonteisten tai muiden henkilöiden tietoja sisältävien aineistojen käsittelyyn. GitHub Pages ja GitHub voivat käsitellä teknisiä lokitietoja omien käytäntöjensä mukaan.

### Rekisterinpitäjä ja yhteydenotot
Projektin lähdekoodin ja dokumentaation ylläpitäjä on Marika Matalamäki. Tietosuojaa koskevat kysymykset voi lähettää osoitteeseen marika.matalamaki@gmail.com. Tämä yhteystieto ei tarkoita, että projekti keräisi kävijöiden henkilötietoja.

### Evästeet ja analytiikka
Projektin ylläpitäjä ei lisää tähän projektiin omia mainos- tai seurant evästeitä eikä omaa analytiikkapalvelua, ellei yllä ole nimenomaisesti toisin kerrottu. GitHubin, GitHub Pagesin, hosting-palvelun ja ulkoisten palveluiden tekninen tietojenkäsittely määräytyy niiden omien tietosuojakäytäntöjen mukaan. Toiminnallisuuden tai palveluntarjoajien muuttuessa tämä dokumentti päivitetään.

### Rekisteröidyn oikeudet
Voit ottaa ylläpitäjään yhteyttä, jos haluat tiedustella mahdollisia projektin ylläpitäjän hallussa olevia henkilötietoja. GitHubin omiin tietoihin liittyvät pyynnöt tulee osoittaa GitHubille.

## English

### Scope
The published browser demo processes pasted HTML and selected SRT or WebVTT subtitle files locally in the visitor's browser. Content is not uploaded to a project server, and the browser demo has no project-owned analytics, user accounts or cookies. The PHP command-line tool is a separate local utility. Do not use the public demo to process confidential, sensitive or other people's personal data. GitHub Pages and GitHub may process technical logs under their own policies.

### Controller and contact
The source code and documentation are maintained by Marika Matalamäki. Privacy questions can be sent to marika.matalamaki@gmail.com. This contact detail does not mean that the project collects visitor personal data.

### Cookies and analytics
The maintainer does not add project-owned advertising or tracking cookies or a project-owned analytics service unless expressly stated above. Technical processing by GitHub, GitHub Pages, hosting providers and external services is governed by their own privacy notices. This document should be updated if project functionality or providers change.

### Data protection rights
You may contact the maintainer to ask about personal data the maintainer may hold in connection with the project. Requests concerning data held by GitHub should be directed to GitHub.
